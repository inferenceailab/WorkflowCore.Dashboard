# Getting help

- **Read the docs first**: the [documentation](docs/Home.md) and the [FAQ](docs/FAQ.md) answer most setup questions.
- **Questions and ideas**: use [GitHub Discussions](https://github.com/inferenceailab/WorkflowCore.Dashboard/discussions).
- **Bugs**: open an [issue](https://github.com/inferenceailab/WorkflowCore.Dashboard/issues/new/choose) with the bug template, including versions and steps to reproduce.
- **Security problems**: report them privately, see [SECURITY.md](SECURITY.md).
- **Workflow Core itself** (the engine, persistence providers, the DSL): ask in the [Workflow Core repository](https://github.com/danielgerlag/workflow-core).

This is a community project maintained in spare time, so there is no guaranteed response time.
